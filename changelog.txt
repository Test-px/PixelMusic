Full Beta-3 Release Note (Refined & Grounded)
 * Next-Gen Stream Engine (WEB_REMIX): Completely rebuilt audio extraction from scratch. Pixel Music now resolves streams directly via a native WEB_REMIX client backed by an on-device QuickJS cipher solver—eliminating 403 errors and dropping heavy third-party scrapers entirely.
 * Next-Gen Fluid Animations (Android 13+): Introduced buttery-smooth, high-quality AGSL (Android Graphics Shading Language) visual animations that react beautifully to your music on modern devices.

 * Complete Download Fix: Resolved the persistent 4-second timeout and track demuxing failures. M4A/AAC files now download, tag with precise metadata, and export to your local storage flawlessly.
 * UI & Navigation Polish: Fixed an overlapping layout bug affecting the shuffle button when using traditional 3-button system navigation.
 * Under-the-Hood Polish: Squashed various unknown background bugs, memory leaks, and edge-case crashes for a rock-solid listening experience.
